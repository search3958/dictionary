<cite>

著作物要素。書籍、論文、楽曲、映画などのタイトルを示すために使用されます。

info

概要

<cite> 要素（サイテーション要素）は、著作物（書籍、記事、映画、写真、彫刻などのクリエイティブ作品）のタイトル を示します。
この要素を使用することで、ブラウザや検索エンジンに対して、そのテキストが引用元や参照元の作品名であることを明確に伝えます。
視覚的には、通常イタリック体（斜体）で表示されます。

list

属性 (Attributes)

属性名 説明
グローバル属性 全ての HTML 要素で使用できる共通の属性（例: class, id, lang, style など）のみ対応しています。<cite> 独自の属性はありません。
code

実用例

1. 書籍のタイトル

<p> プログラミングを学ぶために、<cite> Web開発の基礎 </cite> を読みました。 </p>

2. 映画のタイトル

<!-- 映画名 --> <p> 私の最も好きな映画は <cite>千と千尋の神隠し</cite> です。 </p>

3. 記事のタイトルと引用

<blockquote cite="https://example.com/article1"> <p>セマンティックHTMLはアクセシビリティを高めます。</p> <footer> — <cite>HTML5の正しい使い方</cite> より </footer> </blockquote>

知っておくと良い知識

text_fields
<cite>と著作者の区別
<cite> 要素は、著作物（作品）のタイトル のためにのみ使用します。
著作者の名前 や 人物名 をマークアップするために使用してはいけません。著作者名は、単なる <p> や <span> でマークアップします。
format_italic
視覚的なデフォルトスタイル
多くのブラウザでは、<cite> 要素の内容はデフォルトでイタリック体（斜体）で表示されます。
スタイルを適用したい場合は、CSSで上書きすることが可能です。
