<ol>

順序付きリスト（Ordered List）要素。項目に順序が必要なリストを作成するために使用されます。

info

概要

<ol> 要素は、項目が順序を持つリスト（順序付きリスト）を作成します。各リスト項目は <li> 要素で表され、デフォルトでは数字で番号付けされます。
手順、ランキング、目次など、項目の順序が意味を持つ場合に適しています。

play_circle

静的デモ

HTML
<ol> <li>最初のステップ</li> <li>次のステップ</li> <li>最後のステップ</li> </ol> <br> <ol start="3" type="I"> <li>その後の項目</li> <li>さらに続く項目</li> </ol>
Preview (Result)
  1. 最初のステップ
  2. 次のステップ
  3. 最後のステップ

  1. その後の項目
  2. さらに続く項目
list

属性 (Attributes)

属性名 説明
start リストの開始番号を指定します。デフォルトは1です。
type 使用する番号付けマーカーの種類を指定します。
1: 数字 (デフォルト)
a: 小文字アルファベット
A: 大文字アルファベット
i: 小文字ローマ数字
I: 大文字ローマ数字
reversed リストの順序を降順（逆順）にします。論理属性（値を指定する必要なし）です。
code

実用例

1. 開始番号を指定したリスト

<ol start="5"> <li>アイテム5</li> <li>アイテム6</li> </ol>

2. ローマ数字と逆順のリスト

<ol type="I" reversed> <li>第3位</li> <li>第2位</li> <li>第1位</li> </ol>

3. リスト項目内での段落や入れ子リスト

<ol> <li> <p>最初の段落</p> <ol> <li>ネストされた1</li> <li>ネストされた2</li> </ol> </li> <li>次の項目</li> </ol>
lightbulb

知っておくと良い知識

format_list_numbered
適切なリストの選択
項目の順序が意味を持つ場合は <ol> (順序付きリスト)を、順序が重要でない単なる項目の羅列の場合は <ul> (順序なしリスト)を使用することが、セマンティクス（意味）上重要です。
accessibility_new
セマンティクス（意味）とスタイル
リストの番号付けのスタイル（数字、アルファベットなど）を変更したい場合でも、通常はCSSの list-style-type プロパティを使用することが推奨されます。type 属性は、番号付けの種類が文書の構造上重要な場合にのみ使用するのがベストプラクティスです。
